# CSS Cascadings Style Sheets

Linguagem para definir a estilização de uma página html. Funciona como um dicionário, em que você tem as propriedades e atribui valores como as cores, fontes, tamanhos, mas você pode ter uma precisão e customização melhor do que apenas se fosse html.

Para você poder estilizar algum elemento html, você precisa selecioná-lo, então existem:

- type selector
- id selector
- ID selector
- attribute selector

Para implementá-la no html você pode usar uma tag no head de `<style><\style>`, mas se for algo muito grande, pode ser feito em um arquivo separado, .css e no html é colocado uma tag `<link href="sytle.css" rel="stylesheet">`
