# Javascript

Linguagem de programação do lado do cliente que consegue manipular o DOM, a estrutura do página e trazer um dinamismo a ela.
Temos de volta condições, que são semelhantes ao C:
```javascript
if (x < y){

} else if (y == x) {

} else {

}
```
Para variáveis, já é um pouco diferente, se declara uma com `let`, `let variavel = 0;`
Loops também é semelhante a C:
```javascript
for (let i = 0; i < 3; i++){

}

while(true){

}
```

Para aderir os códigos ao html, você pode colocar uma tag `<script> </script>` direto no html, com código dentro, ou nesssa tag, passar um src para o arquivo. Essa tag pode estar na head, ou no body, no final de tudo.

Javascript, com browser pode trabalhar com eventos, clicando em botões, arrastando, movendo o mouse, clicar com o dedo. Todos esses eventos são traduzidos para javascript que pode ouvir eles e responder a eles, criando assim páginas responsivas.
